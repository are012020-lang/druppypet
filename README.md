# Druppy Pet Shop — demonstrativo do site

Site estático pronto para publicar: `index.html` na raiz e mídias locais na pasta `imagens/`.

## Estrutura

- `index.html` — página completa, responsiva e mobile-first.
- `imagens/logo-druppy.jpg` — marca recortada do perfil enviado.
- `imagens/hero-destaque.jpg` e `imagens/pets/` — fotos dos pets clientes.
- `imagens/videos/druppy-01.mp4` e `druppy-02.mp4` — vídeos recebidos.

## Publicar

Extraia o ZIP e envie **o conteúdo da pasta** para a raiz do repositório GitHub, preservando a estrutura: `index.html` e `imagens/`. Não envie apenas o ZIP fechado.

Para hospedagem estática, publique a raiz do projeto; não há etapa de build.
